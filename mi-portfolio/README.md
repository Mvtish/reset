# Portfolio Personal - Matias Soto

Portfolio profesional desarrollado con React, Vite y Tailwind CSS.

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build
```

## 📦 Tecnologías

- React 19.2
- Vite 7.2
- Tailwind CSS 3.4
- Swiper 12
- Bootstrap Icons
